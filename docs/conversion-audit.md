# BoomBox TH — Conversion Audit & Improvement Notes

## ภาพรวมปัญหา

จากข้อมูล 300 sessions และ 0 LINE add-friend conversions ปัญหาไม่ใช่แค่จำนวนปุ่ม แต่คือ **ข้อเสนอ (offer) ยังไม่ชัดพอเมื่อผู้ใช้ต้องตัดสินใจ** และเส้นทางจากหน้าเว็บไป LINE มี friction ที่ไม่จำเป็น

> เป้าหมายของหน้า: ให้ผู้ใช้เข้าใจว่า BoomBox TH ช่วยอะไร, รู้ว่าจะได้อะไรเมื่อกด LINE, และกดได้ทันทีโดยไม่ต้องคิดว่าต้องซื้อเลยหรือไม่

## จุดรั่วที่พบ

1. **CTA หลักอยู่หลังวิดีโอ 3 คลิป** — ผู้ใช้ที่พร้อมคุยถูกบังคับให้ดู/เลื่อนก่อนถึง action
2. **คำว่า “รับโปร” ไม่บอกผลลัพธ์** — ไม่ชัดว่าได้คูปอง, ราคา, คำแนะนำ หรือจะต้องสั่งซื้อทันที
3. **ปุ่มแพ็กเกจใช้คำว่า “ดูรายละเอียด”** — ฟังเหมือนอ่านข้อมูลต่อ ไม่ใช่ก้าวถัดไปของ funnel
4. **เปิด LINE หน่วง 700ms** — เพิ่มจังหวะที่ผู้ใช้อาจปิดหน้า/เปลี่ยนใจ โดยไม่ได้ให้ประโยชน์กับผู้ใช้
5. **Countdown แบบ localStorage ต่อผู้ใช้** — ไม่ใช่ deadline จริงเดียวกันทุกคน จึงมีความเสี่ยงลดความน่าเชื่อถือและทำให้ scarcity ดูปลอม
6. **Mobile CTA เดิมเป็นปุ่มลอยขนาดเล็ก** — มองเห็นได้ แต่ไม่เด่นพอและไม่ใช้พื้นที่ action ที่ผู้ใช้คุ้นเคยบริเวณด้านล่างจอ

## สิ่งที่ปรับใช้แล้ว

### Copywriting & Value Proposition

- Hero เปลี่ยนเป็น: “อยากเปลี่ยนกลิ่นได้ทุกวัน? เลือกกลิ่นที่ชอบ พร้อมใช้ใน 3 วินาที”
- แสดงราคาเริ่มต้น 299 บาทในบริบทเดียวกับประโยชน์และเงื่อนไข “เก็บเงินปลายทาง”
- เพิ่ม offer card ใต้ headline: “รับคำแนะนำฟรี + ดู Set ที่เหมาะกับคุณ”
- เปลี่ยน CTA จาก “รับโปร” เป็น “คุยกับทีมงานใน LINE”, “ให้ทีมงานช่วยเลือก Set ฟรี” และ “ขอคำแนะนำฟรีใน LINE”
- ระบุ microcopy ว่า “กดแล้วเปิด LINE ทันที” เพื่อลดความไม่แน่ใจ

### UX/UI & Funnel

- ย้าย CTA หลักขึ้นมา **ก่อนวิดีโอ** เพื่อให้ผู้ใช้ที่มี intent สูงกดได้ทันที
- เปลี่ยนปุ่มการ์ดราคาเป็น “เลือก Set A/B/C/D” ซึ่งสื่อว่าเป็นขั้นตอนถัดไป แม้ยังเปิด modal ให้ตรวจรายละเอียดได้
- เอา countdown แบบเฉพาะเครื่องออก และใช้ข้อความราคา/เงื่อนไขที่ตรวจสอบได้แทน
- เปิด LINE ทันทีโดยไม่หน่วง 700ms
- ปรับ floating CTA บนมือถือเป็น sticky bottom bar เต็มความกว้าง รองรับ safe-area ของ iPhone และยังใช้ข้อความ “ขอคำแนะนำฟรี”

## สิ่งที่ควรเพิ่มต่อเพื่อสร้าง Trust

- ภาพสินค้าจริงของเครื่องแต่ละสีและภาพแพ็กจริง (ไม่ใช้ artwork fallback เป็นหลัก)
- รีวิวที่มีหลักฐานประกอบ เช่น ภาพลูกค้า, วันที่สั่งซื้อ, หรือ screenshot การจัดส่ง โดยต้องใช้ข้อมูลจริงเท่านั้น
- ข้อมูลธุรกิจที่ตรวจสอบได้: ช่องทางติดต่อ, เวลาตอบแชต, เงื่อนไขเปลี่ยนคืน, และรายละเอียดการจัดส่ง
- อธิบายให้ชัดว่า “40 กลิ่น” และ “เม็ดบีท” คืออะไร โดยใช้ภาพ/วิดีโอสั้น 1 ชิ้น
- เพิ่ม post-click expectation ใน LINE OA เช่น greeting message/quick reply: “เลือกกลิ่นให้ฉัน”, “ดู Set 299”, “ถามวิธีใช้”

## แผนวัดผลที่แนะนำ

ตั้ง baseline ใหม่ 7–14 วัน โดยใช้ event ที่มีอยู่แล้ว:

- `package_view`: ผู้ใช้เปิดรายละเอียดแพ็กเกจ
- `package_select`: ผู้ใช้เลือกแพ็กเกจ
- `line_click`: ผู้ใช้กด CTA ไป LINE

คำนวณ funnel:

```text
CTA rate = line_click / sessions
Package interest = package_view / sessions
Package-to-LINE = line_click / package_view
```

แยกตาม `utm_source`, device type และตำแหน่ง CTA เพื่อดูว่า traffic ไหนมี intent สูง และวัดเพิ่ม:

- Hero CTA vs sticky mobile CTA
- “คุยกับทีมงานใน LINE” vs “ให้ทีมงานช่วยเลือก Set ฟรี”
- หน้าแรกที่มีวิดีโอก่อน CTA vs CTA ก่อนวิดีโอ (เวอร์ชันปัจจุบัน)

> อย่าตัดสินผลจาก 300 sessions เพียงอย่างเดียว ควรเก็บอย่างน้อย 1–2 สัปดาห์หรือจนมี event `line_click` เพียงพอสำหรับเทียบแนวโน้ม
