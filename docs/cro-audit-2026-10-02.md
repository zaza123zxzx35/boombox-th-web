# BOOMBOX TH — Landing Page CRO Audit

**วันที่ตรวจ:** 2 ตุลาคม 2026  
**Scope:** First-time visitor experience, UX/UI, copy, trust, LINE funnel, mobile friction และ tracking ที่มีอยู่ใน Repository ล่าสุด

> รายงานนี้เป็นการ audit จาก source code, asset structure และ funnel logic ใน Repository ไม่ใช่ผลจากการเปิดหน้าเว็บด้วย real-user session 300 ราย ดังนั้นส่วนที่เกี่ยวกับ traffic quality และ LINE add-friend สำเร็จต้องตรวจจาก analytics จริงเพิ่มเติม

## Executive verdict

**Conversion readiness: 66/100**

หน้าเว็บไม่ได้ขาดปุ่ม CTA แล้ว และมีการปรับ Hero/ภาพสินค้า/รีวิวดีขึ้นมาก แต่ยังไม่ควรสรุปว่า 0% เกิดจาก Design อย่างเดียว เพราะมีความเสี่ยงสูงว่า **tracking ของ `line_click` ไม่ทันถูกบันทึกก่อน browser เปลี่ยนไป LINE** และระบบในปัจจุบันก็ไม่ได้วัด “แอดเพื่อนสำเร็จ” จริง วัดได้เพียงการพยายามคลิกออกจากเว็บ

## 3 สาเหตุหลักที่อาจทำให้เห็น Conversion 0%

### 1. Tracking อาจวัดต่ำกว่าความจริง

ใน `handleLineCtaClick()` มีการเรียก mutation แบบ asynchronous แล้วเรียก `window.location.assign(LINE_ADD_FRIEND_URL)` ทันที:

```ts
trackEngagement("line_click", packageCode);
window.location.assign(LINE_ADD_FRIEND_URL);
```

เมื่อ browser unload หน้าเว็บ request ที่กำลังส่งอาจถูก cancel ทำให้ฐานข้อมูลไม่รับ `line_click` แม้ผู้ใช้กดจริง

**ผล:** ตัวเลข 0 อาจเป็น measurement failure ไม่ใช่ 0 clicks จริง

นอกจากนี้ LINE add-friend เป็น external action จึงไม่สามารถยืนยันจากเว็บได้ว่าผู้ใช้กด “เพิ่มเพื่อน” สำเร็จแล้ว การนับ `line_click` จึงเป็น proxy metric เท่านั้น

### 2. Traffic อาจไม่ใช่ Buyer Intent

300 visitors อาจเป็นคนที่กดจากวิดีโอ/โพสต์เพราะอยากรู้อยากเห็น ไม่ใช่คนที่กำลังหาสินค้านี้ หากไม่มี UTM, source, landing time, scroll depth และ device breakdown จะยังวินิจฉัย traffic ไม่ได้

### 3. Trust และความเข้าใจสินค้าไม่ถึงจุดตัดสินใจ

ผู้ใช้ใหม่ต้องเข้าใจในไม่กี่วินาทีว่า:

- สินค้าคืออะไร
- ใช้กับอะไร
- ได้อะไรใน Set A ฿299
- ส่งฟรีจริงหรือไม่
- ต้องแอด LINE เพื่ออะไร
- แอดแล้วโดนบังคับซื้อหรือไม่

หน้าเว็บตอบหลายข้อแล้ว แต่ยังมี copy หลายชุดซ้อนกัน และรีวิวแบบข้อความที่ไม่เห็นหลักฐานชัดเจนอาจลดความไว้วางใจแทนที่จะเพิ่ม

## Action plan: P0 ต้องทำก่อนยิง traffic ต่อ

### P0.1 แก้ tracking ให้ทนต่อ page unload

ใช้ `navigator.sendBeacon()` หรือ `fetch(..., { keepalive: true })` สำหรับ event สำคัญ โดยเฉพาะ `line_click` แทนการหวังให้ mutation ปกติส่งทันก่อน redirect

อย่างน้อยให้มี client-side backup:

```ts
window.dispatchEvent(new CustomEvent("boombox-line-click", {
  detail: { packageCode, source, ctaPosition },
}));
```

และส่ง server event ด้วย `keepalive`/Beacon

### P0.2 แยกตำแหน่ง CTA

เพิ่ม `ctaPosition` ใน event schema:

```text
hero
header
sticky_mobile
package_A
package_B
package_C
package_D
faq
footer
```

ปัจจุบัน schema มี `source` แต่ยังไม่รู้ว่าคลิกจากจุดไหน ทำให้ตัดสินใจ optimize CTA ไม่ได้

### P0.3 สร้าง test URL และตรวจบนอุปกรณ์จริง

ทดสอบ:

- iPhone Safari
- Android Chrome
- Facebook in-app browser
- Instagram in-app browser
- LINE in-app browser
- desktop browser ที่ไม่มี LINE application

ตรวจว่า URL นี้เปิดได้จริง:

```text
https://line.me/R/ti/p/@425syacj
```

## Offer & Lead Magnet

ไม่ควรแจกคูปองปลอมเพื่อบังคับให้แอด ควรใช้สิ่งที่ทีมงานส่งให้ได้จริงหลังแอด เช่น:

### Lead magnet ที่เหมาะกับสินค้า

> **คู่มือเลือกกลิ่นฟรี 1 นาที**  
> ทัก LINE แล้วตอบ 3 คำถาม ทีมงานช่วยแนะนำกลิ่นและ Set ที่เหมาะกับคุณ

หรือ:

> **รับรายการ 40 กลิ่น + คำแนะนำกลิ่นยอดนิยมฟรีทาง LINE**

CTA:

> **รับรายการกลิ่นฟรีใน LINE**

การใช้ lead magnet นี้ดีกว่า “รับโปร” เพราะผู้ใช้รู้ว่ากดแล้วจะได้อะไร และไม่รู้สึกว่ากำลังถูกบังคับซื้อ

## UI/UX ที่ควรปรับต่อ

1. ลด Hero จากวิดีโอ 3 คลิปเหลือ **1 hero demo ที่สื่อขั้นตอนชัดที่สุด** แล้วให้คลิปอื่นอยู่ถัดลงมา
2. เพิ่มป้ายสั้นใต้ Hero: `เลือกกลิ่น → ใส่เม็ด → กดใช้ → พร้อมใน 3 วิ`
3. ให้ CTA หลักมี secondary action แบบ anchor: `ดูว่า Set A ได้อะไร` เพื่อคนที่ยังไม่พร้อมแอด
4. ทำ Set A เป็นการ์ดเด่นเพียงใบเดียว และเปลี่ยน B เป็น `คุ้มค่าสำหรับคนที่เลือกกลิ่นเอง` ไม่ควรมีหลายการ์ดที่ดึงความเด่นพร้อมกัน
5. ใน Modal แสดง “สิ่งที่จะได้รับ” เป็น checklist ก่อน selector และแสดง `ส่งฟรี + COD` ใกล้ปุ่ม LINE
6. รีวิวควรแบ่งเป็น `ภาพหลักฐานจากลูกค้า` กับ `ข้อความรีวิวที่มี source` ไม่รวมเป็น carousel ยาวที่เลื่อนอัตโนมัติ
7. เอา `verified-badge` ออกหรือเปลี่ยนเป็น `ภาพรีวิวจากลูกค้า` หากยังไม่มี verification system
8. เพิ่ม CTA หลัง proof gallery โดยตรง ไม่ต้องรอถึง package section

## Traffic qualification plan

### Campaign structure

| Campaign | กลุ่ม | เป้าหมาย |
|---|---|---|
| Cold: product demo | คนที่สนใจสินค้า/ไลฟ์สไตล์และพฤติกรรมซื้อออนไลน์ | ให้เข้าใจสินค้า ไม่เน้นขายแรง |
| Warm: video viewers | คนดูวิดีโอ 25–50% และเข้าเว็บเกิน 30 วินาที | พาไปดู Set A / LINE |
| Hot: package viewers | คนเปิด Set A/B/C/D หรือกด CTA | ปิดการขาย/ช่วยตอบข้อสงสัย |

### Ad copy สำหรับคัดกรองตั้งแต่ต้น

> BoomBox TH คืออุปกรณ์เปลี่ยนกลิ่นจากเม็ดบีท  
> Set A ฿299 ได้เครื่อง 1 เครื่อง เลือกสีดำ/ขาว + เม็ดรวม 100 เม็ด สุ่มจาก 40 กลิ่น  
> ส่งฟรี เก็บเงินปลายทาง  
> ทัก LINE ให้ทีมงานช่วยเลือกก่อนสั่งได้

ข้อความนี้จะลด click ที่เกิดจากความเข้าใจผิด เพราะบอกสินค้า ราคา สิ่งที่ได้ และวิธีชำระเงินตั้งแต่ Ad

### Exclude/แยกกลุ่ม

- คนที่ดูหน้าเว็บต่ำกว่า 5 วินาที: อย่าใช้เป็น seed ของ lookalike
- คนที่กดซ้ำหลายครั้งแต่ไม่มี engagement: แยกออกจากกลุ่ม buyer intent
- คนที่อยู่นอกพื้นที่จัดส่งหรือกลุ่มอายุที่ไม่เหมาะกับสินค้า: exclude ตามเงื่อนไขธุรกิจและ policy platform
- แยก organic, paid, referral และ direct ด้วย UTM

## Final verdict

**หน้าเว็บปัจจุบันอยู่ที่ประมาณ 66/100 ในมุม Conversion—not bad, but not ready to blame traffic alone.**

สิ่งที่ควรทำก่อนเพิ่มงบโฆษณาคือ:

1. แก้ tracking unload และตรวจ LINE link บนอุปกรณ์จริง
2. ตัด/ติดป้ายรีวิวที่ไม่สามารถยืนยันแหล่งที่มาได้
3. ทำ lead magnet ที่ชัด เช่นรายการ 40 กลิ่น + ช่วยเลือก Set ฟรี
4. ยิง Ad ที่อธิบายสินค้าก่อนขาย และแยก cold/warm/hot traffic
5. แยก CTA position เพื่อรู้ว่าคนกดจากจุดใด

ถ้าทำ 5 ข้อนี้แล้ว ยังได้ 0% จาก qualified traffic จริง ค่อยกลับมาแก้ offer/ราคา/ความน่าเชื่อถือเชิงธุรกิจต่อ — ไม่ควรรีบเปลี่ยนสีปุ่มหรือเพิ่ม animation ก่อนแก้ measurement และ message-market fit
